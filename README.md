## 广港 IEPL 总被点名的原因

跨境电商、TikTok Shop、Shopee、独立站后台这一类业务，对网络的硬性要求集中在三点：低延迟、稳定路由、以及较高的合规性。广州 BGP 入香港 IEPL 这条线正好把这三点凑齐。

- **端内延迟 1~2 ms**：这是 IEPL 专线层的端到端数字，不含客户端到接入点的本地网络。从广州本地办公或 IDC 接入，到香港出口 BGP 跳，大部分场景的实际延迟落在 5~10 ms 之间，比走普通 CN2/GIA 跨境节省半个数量级。
- **IEPL 底层而非优化路由**：IEPL（International Ethernet Private Line）是真正的端到端以太网专线，跨境的 QoS 不会因为某一段公网拥塞突然抖动。优化路由速度快但"忙时降速",专线则把跨境这一段锁住。
- **入口可选项多**：广州八线动态 BGP、电信、移动、联通、广东三线、上云互联优化入口（IXP）几类入口都在同一产品页可选，按你机房或办公环境的现有网络最方便的入口对应起来即可。

合规方面，这条线不是 VPN、不靠机场方案、也不是海外住宅 IP，而是真实署名的中国身份证实名 + 香港出口公网 IP 的云服务器/独立服务器形态，符合公开跨境业务的平台审核习惯。

## 流量计费版的规则必须先念清楚

很多人下单前没读完"流量计费"这四个字的含义，结果到月中被暂停才开始查问题。规则其实就几条：

- **共享带宽**：套餐标注的 200M、300M、500M、1G 是带宽**峰值**，不保证持续跑满。买个 500M 套餐，不代表永远能在云内以 500M 速率上传/下载。短促任务（如 API 拉取、批量上传）能享受峰值，长时间高强度下载需要留意是否能持续满速。
- **月流量双向统计**：流量按上行、下行双向累计，不是仅统计出口。这和"我只下发一点点"的直觉相反——如果业务侧有大文件上行（备份、同步、推送），月度流量会很快被吃掉。
- **超量后暂停服务**：当月流量用尽后，套餐会被暂停，不是自动按量计费。可在后台"自助购买流量重置"恢复当前套餐价格，或者提交工单补差价升级到更高档。
- **升降级走工单**：套餐升降级不在购物车里直接点，需要提交工单办理；中级降级到更低档套餐时差价不退，是否迁移按工单处理结果为准。

还有一条不算计费但和账单相关的限制：现行退款政策仅支持 24 小时内可证明的**质量问题**退款，需要在工单中提供延迟数据、测速截图等具体证据，开通后不支持更换到其他地域。换句话说，下单前的需求确认远比下单后的退订重要。

## 这条线路适合谁

从过去几个月的社区讨论与官方资料看，选广港 IEPL 流量计费版的高频场景主要是这几类：

- **Shopee / TikTok Shop 多店铺后台运营**：延迟低、独享进+出 IP、不容易因为共享 IP 触发风控，1 TB ~ 2 TB 起步档对应常见工作量。
- **跨境电商独立站数据同步**：把独立站订单、客户信息回传到 ERP 系统的批量任务，2 TB ~ 4 TB 档更合适。
- **远程办公人员使用海外平台后台**：从华南办公室直接连香港出口访问海外平台，端内延迟 1~2 ms 体现在操作体验上是明显的。
- **小型数据采集 / API 拉取任务**：月流量不夸张但 CPU 多任务频繁，2 TB 档（2 核 4 GB）的配置比 1 TB 档更稳。
- **服务商 / 多账号批量管理**：这类任务月流量容易推到 6 TB 以上，需要直接走 6 TB / 10 TB 档。

不适合这条线路的情形主要有：纯境内业务（绕远路）、对延迟不敏感但对月费极敏感（直接走普通 CN2 或 IXP）、需要在境外部署双向公开服务（IEPL 不支持外部连入，仅 VPS 内推业务流量向出口）。

## 常见问题

**Q1：广港 IEPL 的 1 TB 套餐买来够不够用？**
看业务类型。如果是几个店铺的日常运营、定期拉取数据，1 TB 一般够；如果有批量上传备份、视频推流等大动作，2 TB 起更稳。

**Q2：流量是按上行还是下行算？**
双向统计。上行拉数据、下行接收数据都会计入月流量配额，超量后服务会暂停。

**Q3：套餐标注的 500M 带宽是可以一直跑 500M 吗？**
不是。共享带宽是峰值，不保证持续速率；持续占用需要看独享带宽档位。

**Q4：超量了怎么办？**
可在后台购买"流量重置"恢复继续使用，或提交工单补差价升级到更高档。下单前大致估算月流量能省很多事。

**Q5：买了以后能换地理或换线路吗？**
开通后不支持换地域或换其他线路；升降级走工单处理，降级差价不退。

**Q6：广港 IEPL 与沪日/沪美怎么对应选？**
香港出口覆盖国际通用性最强的电商/SaaS 后台；日本出口适合日本平台/特定服务；美国出口对应北美平台/支付回调。先按目标出口方向锁定，再在该线路档位中选流量档。

**Q7：需要中国手机号码吗？**
需要。个人用户实名需手机号 + 姓名 + 身份证号；企业用户需营业执照 + 法人身份证 + 对公账户。
